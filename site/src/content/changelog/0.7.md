## New

- **New note “…”** in the command palette: type a title, pick the last command, and the note is made with that name. It is what the palette offers when nothing is found.
- **Search and New note at the top of the page** while the sidebar is hidden, which on a phone is always. One tap from any note, the overview, Activity or Settings. On phones the star moved into the ⋯ menu to make room.
- **Trash** in the sidebar: while the Trash holds something, it has a row of its own under Activity, with the number of items.
- A link to a note, folder or board that is in the Trash now says so and offers **Restore** right there, instead of "no longer exists".

## Improved

- **Importing a backup is safer.** The dialog shows what is in the file and what is in Lodoc now. **Merge** is the main button. **Replace all…** asks once more and names what will be deleted, and the message afterwards offers **Undo**, which brings everything back until you close or reload Lodoc.
- Restoring a backup into an empty Lodoc no longer asks how: there is nothing to merge with.
- One word for the file: **Export backup** and **Import backup…** replace *Export all notes* and *Import from file…*.
- **Search finds more.** Type several words in any order and a note is found when it has all of them, each one highlighted. A phrase in "quotes" is still searched exactly as typed.
- Search results are ordered by how well they match: notes with your words in the title come first, then the ones edited last.
- Search no longer stops at 8 notes without saying so: **Show all … notes** lists the rest.
- A new folder made with **New… → Folder**, the command palette or **New subfolder** opens with its name selected: type the name and press `Enter`.
- Long folder names wrap on the folder's page instead of being cut off.

## Fixed

- After a backup replaced everything, the Scratchpad on the overview could stay empty until a reload.
