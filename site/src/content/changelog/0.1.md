## New

- A block editor for notes: headings, lists, checklists, quotes, code, tables and images, with `/` for every block and Markdown shortcuts like `#` and `-`.
- Folders inside folders, and notes outside any folder under **Unfiled**.
- Drag notes and folders in the sidebar to reorder them or move them into another folder.
- Sort the notes in a folder by last edit, creation, title or length.
- A cover image above a note: upload one, or drop an image file on it.
- Light and dark mode.
- Everything is stored in this browser only, with no account and no server. **Export** saves it all as one file, and **Import** brings it back, merged with what's there or replacing it.
