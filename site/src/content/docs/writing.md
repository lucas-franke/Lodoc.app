A note is made of blocks: paragraphs, headings, lists, checklists, quotes, code, tables, images and files. Each block can be moved by its handle on the left.

## Blocks and shortcuts

- Type `/` at the start of a line to pick a block.
- Markdown shortcuts work as you type: `#`, `##` or `###` and a space for a heading, `-` for a list, `1.` for a numbered list, `[]` for a checklist, `>` for a quote.
- Select text to make it bold, italic, a link and more. `Ctrl` + `K` turns selected text into a link.
- Typed arrows become arrows: `->` →, `<-` ←, `<->` ↔, `=>` ⇒. Press `Backspace` right after to keep what you typed.
- Paste or drop images straight into a note. They are made smaller as they come in, so notes stay light.

## Links between notes

Type `@` and pick a note to link to it, or type a new name to create that note. A link always shows the note's current title. At the bottom of every note, **Linked from** lists the notes that link to it.

## Tags

Write a tag anywhere in the text, like `#idea`, and the note gets it. Typing `#` after a space suggests the tags you already use. You can also add tags with **Add tag** under the title. Every tag has a page with all its notes: `Ctrl`-click a tag in the text, or find it under **Tags** in the sidebar.

Taking a tag out of the text removes it again. Tags added with **Add tag** stay until you remove them there. Tags in code and plain numbers like `#1` don't count.

## Covers

Every note gets a colour gradient as its cover. Click the cover to pick another gradient, upload an image, drop an image file on it, or remove it. **Shuffle** picks another gradient at random. On cards, a gradient the note got by itself is a thin band of colour at the top; one you picked, or an image, is the card's cover. If you'd rather have covers only where you chose one, turn off *Automatic covers* in [Appearance](../appearance/).

## Templates

**From template** next to *New note* starts a note with a ready-made structure: meeting notes, a daily journal, a project plan or a to-do list. The empty lines say what goes there.

Any note can be a template of its own: choose **Use as template** in its menu (`…`). It appears under *Your templates*, and new notes from it start as a copy.

## History

Lodoc keeps earlier versions of each note: when you change a note, the version it had before is kept, at most every 10 minutes. Choose **History…** in a note's menu to see them and put one back. What the note said just before is kept too, so restoring can be undone. History stays on this device for 90 days and isn't part of backups.

## Little helpers

- Under the title: when the note was last edited and how many words it has.
- Notes with three or more headings show an **On this page** outline on wide screens.
- **Download as .md** in a note's menu saves it as a Markdown file.
